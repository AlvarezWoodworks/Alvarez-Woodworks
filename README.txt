# Alvarez Woodworks — Website + Custom Shop

This folder is a complete static website. It can be opened directly in Google Chrome.

## Open it in Google Chrome
1. Download and unzip `alvarez-woodworks-google-ready.zip`.
2. Open the folder.
3. Double-click `index.html`.
4. If your computer asks which app to use, choose **Google Chrome**.

The site works without installing anything.

## Put it online
Opening it in Chrome is different from publishing it on the internet. For a public website with a real `alvarezwoodworks...` web address, upload the website to a web host such as GitHub Pages, Netlify, or another static web host.

Google Drive is good for storing the ZIP/folder, but it is not a normal website host for running this HTML/CSS/JavaScript as a public site.

## Real card payments
The shop is designed for a secure Stripe Checkout connection, but a real payment processor requires a payment account and a small server-side endpoint. The secret payment key must NEVER be put inside `index.html` or `script.js`.

The current site intentionally sends the order request to Alan.a4014@gmail.com until that secure payment endpoint is connected.

Because payment-provider accounts can have age/contract requirements, have a parent/guardian or other appropriate adult handle the business payment account if needed.
